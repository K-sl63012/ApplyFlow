# ApplyFlow – Internship & Job Application Tracker

ApplyFlow is a responsive SaaS landing page prototype designed to help students and job seekers organise their internship and job application journey.

## Live Demo

https://k-sl63012.github.io/ApplyFlow/

## Features

- Clean and responsive landing page.
- Navigation links to different website sections.
- Hero section with clear call-to-action buttons.
- Feature cards for application tracking, interview management, deadline reminders and progress monitoring.
- How It Works section.
- Free and Pro pricing plans.
- Contact form with input validation and a success message.
- Mobile-friendly navigation menu.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling, layouts and responsive design.
- JavaScript – Form validation and interactive navigation.
- GitHub – Source code management.
- GitHub Pages – Website deployment.

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. View the website in your browser.

## Note

This is a frontend prototype created as part of a front-end development assignment. The contact form currently demonstrates client-side validation and a success message; it does not submit or store information on a server.
